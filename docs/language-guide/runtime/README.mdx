# 実行モデル

命令を読むときは，実行前に必要な値と，実行後に残る値を確認します。メソッド呼び出しごとに持つフレームが，その値の置き場所です。

- [スタックとローカル変数](./stack-and-locals.md)：フレームの構造とスロット配置
- [命令の分類](./instructions.md)：用途と型から命令を探す
- [オブジェクトと配列](./objects-and-arrays.md)：参照の生成，初期化，要素アクセス
- [メソッド呼び出し](./method-invocation.md)：対象・引数・戻り値の受け渡し

[Jaspera](https://jal.yamad.jp/jaspera/) のステップ実行では，停止したフレームの状態を確認できます。操作は [Jaspera で試す](../../usage/jaspera.md) を参照してください。
