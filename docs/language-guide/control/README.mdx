# 制御と検証

分岐や例外処理があるメソッドには，複数の実行経路があります。同じ位置へ入る経路で，スタックとローカル変数の状態が両立するように書きます。

- [制御フロー](./control-flow.md)：ラベル，条件分岐，ループ，switch
- [例外処理](./exceptions.md)：保護範囲とハンドラの指定
- [StackMapFrame と検証](./stackmap-and-verification.md)：合流点と未初期化参照の制約
- [書き方の指針](./style-guide.md)：インデント，名前，コメントの付け方

「書き方の指針」は読みやすさのための提案です。JVM が要求する制約とは分けて説明しています。
