# 言語ガイド

JAL の記法と，生成したバイトコードの動作を説明します。初めて読む場合は「基礎」から順に進めてください。書きたい処理が決まっている場合は，各章から必要なページを選べます。

| 章 | 調べられること |
| --- | --- |
| [基礎](./basics/README.mdx) | クラスファイル，型記述子，クラス・メンバーの宣言 |
| [実行モデル](./runtime/README.mdx) | スタック，ローカル変数，命令，オブジェクトと配列 |
| [制御と検証](./control/README.mdx) | 分岐，例外ハンドラ，スタックマップの条件 |
| [マクロ](./advanced/macros.md) | コンパイル前のソースの置換 |

[Jaspera](https://jal.yamad.jp/jaspera/) では，例の命令を変更して動作を確かめられます。メソッドだけの例はクラスの中へ，命令列だけの例は必要な引数と戻り型を持つメソッドへ置いてください。[メソッド例の実行方法](../usage/examples.md#メソッドだけの例を実行する)に，`main` から呼び出す手順があります。

JAL 独自の記法はコンパイラの実装に従います。JVM の形式と検証規則の原典は [Java Virtual Machine Specification](https://docs.oracle.com/javase/specs/jvms/se25/html/index.html) です。このサイトは JAL の使い方を説明するもので，JVM 仕様全体を置き換えるものではありません。
