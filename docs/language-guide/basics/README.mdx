- [クラスファイルの見方](./class-file-model.md)：コンパイルの出力と定数プール
- [型記述子](./descriptors.md)：フィールド・引数・戻り値の型
- [クラス，フィールド，メソッド](./classes-and-members.md)：宣言と初期化処理

メソッドの中で値をどう扱うかは [スタックとローカル変数](../runtime/stack-and-locals.md) へ続きます。
