# LangJAL ドキュメント

LangJAL は，JVM バイトコードをテキストで記述する言語 JAL と，そのコンパイラ・逆アセンブラを提供しています。このサイトでは，JAL の構文と，命令を実行したときの JVM の動作を説明します。

初めて使う方は [はじめに](./intro.mdx) と [チュートリアル](./usage/tutorial.mdx) を順に読んでください。ブラウザでコードを書いて試すには，サンドボックス実行環境 [Jaspera を開く](https://jal.yamad.jp/jaspera/) と始められます。JDK のインストールは不要です。

## 書き方を調べる

- [構文ガイド](./language-guide/basics/syntax.md)：クラス，フィールド，メソッドの記法
- [型記述子](./language-guide/basics/descriptors.md)：`I` や `Ljava/lang/String;` の読み方
- [スタックとローカル変数](./language-guide/runtime/stack-and-locals.md)：値の受け渡しとスロット番号
- [命令の分類](./language-guide/runtime/instructions.md)：目的から命令を探す
- [制御フロー](./language-guide/control/control-flow.md)と[例外処理](./language-guide/control/exceptions.md)：分岐先と保護範囲の指定

## 実行して確かめる

[Jaspera の使い方](./usage/jaspera.md)では，実行，ブレークポイント，ステップ実行，フレーム表示を説明します。ドキュメントで命令の意味を調べ，Jaspera で値や分岐を変えて確かめてください。

手元の JVM で実行する場合は [CLI・IDE・Gradle](./usage/tooling.md) を参照してください。文法や説明に問題を見つけた場合は，[LangJAL の Issues](https://github.com/JVMLand/LangJAL/issues) に該当ページとコード例を添えて報告できます。
