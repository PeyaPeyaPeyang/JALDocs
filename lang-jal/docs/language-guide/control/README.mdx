# 制御と検証

この階層では、ラベルや分岐で制御フローを作る方法と、JVM の検証を通る命令列を書くための考え方を扱います。JAL は StackMapFrame を自動生成しますが、スタックの高さや型が各経路で整合している必要はあります。
