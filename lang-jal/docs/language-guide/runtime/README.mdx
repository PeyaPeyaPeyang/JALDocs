# 実行モデル

スタック，ローカル変数，命令，オブジェクト，配列，メソッド呼び出しの入口。

---

この階層では，JAL の命令列が JVM 上でどう動くかを扱います。JVM はスタックマシンなので，値がどの順番で積まれ，どの命令で消費されるかを追うことが重要です。
