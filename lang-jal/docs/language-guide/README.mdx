# 言語ガイド

言語ガイドは、JAL の構文を「ファイル構造」「型とメンバー」「スタックと命令」「制御フローと検証」に分けて説明します。JAL は JVM クラスファイルに近い言語なので、Java ソースの文法だけでなく、JVM が実行時に見る構造も一緒に理解すると読みやすくなります。

## おすすめの読み順

1. [基礎](./basics/README.mdx) で、構文、クラスファイル、型記述子、メンバー定義を確認する
2. [実行モデル](./runtime/README.mdx) で、スタック、ローカル変数、命令、呼び出しを追う
3. [制御と検証](./control/README.mdx) で、分岐、例外、StackMapFrame、書き方の指針を押さえる
