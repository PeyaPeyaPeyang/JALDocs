# はじめに

JAL（Java Assembly Language）は，Java Virtual Machine 向けのテキストアセンブリ言語です。JVM バイトコードに直接対応する構造を保ちながら，ラベル，名前付きローカル変数，読みやすいメンバー参照，構造化された例外処理を使って `.class` を生成できます。

JAL は，機械語やアセンブリ言語の入門にも使えることを意識しています。x86 などの実機向けアーキテクチャは強力ですが，命令，レジスタ，メモリ，ABI，OS との関係を同時に扱う必要があり，最初の題材としては複雑になりがちです。

JVM はそれらに比べると，スタック，ローカル変数，分岐，メソッド呼び出しを中心にした単純なモデルとして観察できます。まず JVM のアセンブリで「命令を並べると機械がどう動くか」を学び，そのあと x86 や他のアーキテクチャへ進むための足場にできます。

Jasmin のような既存の Java アセンブラの考え方を引き継ぎつつ，現代の JVM で必要になる StackMapFrame を自動生成することを重視しています。

## Jasmin があるのに！

[Jasmin](https://jasmin.sourceforge.net/) は JVM バイトコードをテキストで書くための，事実上の標準と言える存在です。Java アセンブリ言語として広く知られており，JVM の低レイヤを扱ううえで重要な先行プロジェクトです。

一方で，Jasmin の文法は JVM の構造をそのまま強く反映しているため，やや複雑で分かりにくい部分があります。初めて JVM バイトコードを学ぶ人にとっては，命令そのものを理解する前に，記法や周辺情報の扱いでつまずきやすい面があります。

JAL は，そうした学びにくさを減らし，よりモダンな Java アセンブリ言語として使えるものを目指して作りました。StackMapFrame の自動生成，名前付きローカル変数，読みやすいメンバー参照，ラベルを使った例外処理，IntelliJ IDEA での補完やデバッグ連携を通じて，JVM を機械語入門の題材としても扱いやすくすることを重視しています。

対応する class ファイルの範囲は Java 1.0 から Java 27 までです。古いバージョンの class ファイルを観察する用途にも，最新の JVM 仕様を追う用途にも使えます。

## 最小のプログラム

```jal
public class HelloWorld (
  major_version=55,
  minor_version=0) {

  public static main([Ljava/lang/String;)V {
    getstatic java/lang/System->out:Ljava/io/PrintStream;
    ldc "Hello, World!"
    invokevirtual java/io/PrintStream->println(Ljava/lang/String;)V
    return
  }
}
```

このプログラムは Java 11 相当の class ファイルとして `HelloWorld` を定義し，`main(String[] args)` から `System.out.println("Hello, World!")` を呼びます。

## JAL が扱いやすくしていること

| 項目 | 内容 |
| --- | --- |
| StackMapFrame | コンパイラが解析して自動生成します。 |
| ローカル変数 | スロット番号だけでなく名前ヒントを使えます。 |
| メンバー参照 | `java/io/PrintStream->println(Ljava/lang/String;)V` のようにクラスとメンバーを分けて書けます。 |
| 制御フロー | ラベル，条件分岐，`goto`，`tableswitch`，`lookupswitch` を明示できます。 |
| IDE 支援 | Javasm IntelliJ Plugin で補完，ドキュメント，デバッグ連携を利用できます。 |

## コンパイル

JAL CLI Compiler をインストール済みなら，次のように `.jal` をコンパイルできます。

```bash
jalc HelloWorld.jal
```

jar として出力する場合:

```bash
jalc HelloWorld.jal --output HelloWorld.jar
```
