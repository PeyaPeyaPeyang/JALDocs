## ドキュメント構造

```text
docs/
  README.mdx
  intro.mdx
  language-guide/
    README.mdx
    basics/
      README.mdx
    runtime/
      README.mdx
    control/
      README.mdx
  usage/
    README.mdx
```

各階層の `README.mdx` は、その階層に含まれるページの案内役です。細かい項目へ直接入る前に、まず階層の README を見ると読み進めやすくなります。
